# PRD: 개발자 프로필 웹사이트 (DemoPort)

## 1. 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 kwan의 역량과 프로젝트를 소개하는 개인 프로필 웹사이트 |
| 개발자 | kwan |
| 이메일 | secuarian@gmail.com |
| 주 개발 분야 | 바이브코딩(Vibe Coding), Python, HTML5 |
| 문서 상태 | Draft v0.1 |

## 2. 배경 및 목표

### 배경
AI와 협업하는 바이브코딩 방식으로 다양한 결과물(게임, 도구 등)을 만들고 있으며, 이를 한곳에 모아 보여줄 수 있는 공개 포트폴리오가 필요하다.

### 목표
- 방문자가 10초 안에 "누구이고 무엇을 하는 개발자인지" 파악할 수 있다.
- 실제 동작하는 데모를 바로 체험할 수 있다.
- 채용 담당자, 협업 제안자, 동료 개발자가 쉽게 연락할 수 있다.

### 성공 지표
- 이메일 문의 링크 클릭 수
- 데모/프로젝트 카드 클릭 수
- 모바일·데스크톱 Lighthouse 점수 90점 이상 (성능, 접근성, SEO)

## 3. 타깃 사용자

| 사용자 | 니즈 |
|--------|------|
| 채용 담당자 | 기술 스택과 경력·프로젝트를 빠르게 확인 |
| 협업/외주 의뢰자 | 결과물 품질 확인, 연락 수단 |
| 동료 개발자 | 바이브코딩 사례와 코드 참고 |

## 4. 주요 기능 (Scope)

### 4.1 필수 (MVP)
1. **Hero 섹션**: 이름(kwan), 한 줄 소개, 주요 분야 태그(Vibe Coding · Python · HTML5), 연락하기 버튼
2. **About**: 개발 철학과 작업 방식 소개 (AI와 협업하는 바이브코딩 워크플로우 중심)
3. **Skills**: 분야별 역량 표시
   - Vibe Coding: AI 도구를 활용한 기획→구현→검증 워크플로우
   - Python: 자동화, 게임, 스크립트, 데이터 처리
   - HTML5: 시맨틱 마크업, Canvas, CSS3, 바닐라 JavaScript
4. **Projects**: 프로젝트 카드 목록 (썸네일, 제목, 설명, 사용 기술, 데모/코드 링크)
   - 초기 항목 예시: Snake 게임(Python, 사람 vs AI), Tetris(HTML5 Canvas)
5. **Contact**: 이메일 `secuarian@gmail.com` (`mailto:` 링크, 복사 버튼)
6. **반응형 레이아웃**: 모바일 / 태블릿 / 데스크톱

### 4.2 선택 (후속 버전)
- 다크/라이트 테마 전환
- 블로그 또는 개발 노트 섹션
- 프로젝트 태그 필터
- GitHub 연동으로 저장소 자동 표시
- 다국어(한국어/영어)
- 방문 통계

### 4.3 제외 (Out of Scope)
- 로그인/회원 기능
- 서버 측 데이터베이스
- 문의 폼의 서버 처리 (MVP는 `mailto:` 링크만 사용)

## 7. 디자인 요구사항

- **톤**: 깔끔하고 개발자다운 미니멀 스타일, 코드/터미널 느낌의 포인트 요소
- **색상**: 어두운 배경 + 1개의 포인트 컬러 (CSS 변수로 관리)
- **타이포그래피**: 본문은 시스템/한글 산세리프, 코드·태그는 고정폭 글꼴
- **애니메이션**: 스크롤 시 섹션 페이드인 등 절제된 효과, `prefers-reduced-motion` 존중
- **접근성**: 명도 대비 WCAG AA, 키보드 탐색, 의미 있는 `alt`와 `aria` 속성

## 8. 기술 요구사항

| 구분 | 내용 |
|------|------|
| 마크업 | HTML5 시맨틱 태그 (`header`, `nav`, `main`, `section`, `footer`) |
| 스타일 | CSS3 (Flexbox/Grid, CSS 변수, 미디어 쿼리) |
| 스크립트 | 바닐라 JavaScript (스크롤 내비, 이메일 복사 등 최소한) |
| 프레임워크 | 없음 (정적 사이트) |
| 호스팅 | GitHub Pages 등 정적 호스팅 |
| 브라우저 | 최신 Chrome, Edge, Safari, Firefox |
| 성능 | 외부 라이브러리 최소화, 이미지 최적화(WebP) |
| SEO | `title`, `meta description`, Open Graph 태그 |

## 11. 열린 질문

- 프로필 사진 또는 아바타 사용 여부
- 포인트 컬러와 전체 분위기(어두운 테마 고정 vs 테마 전환)
- GitHub, 블로그 등 추가 연락처/링크 공개 여부
- 소개 문구에 넣을 경력·학력·자기소개 내용
- 프로젝트 목록에 실제로 공개할 항목 확정
