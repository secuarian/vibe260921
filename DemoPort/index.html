01. About

안녕하세요, 개발자 kwan입니다. 저는 AI 도구와 대화하며 기획부터 구현, 검증까지 이어가는 바이브코딩 방식으로 개발합니다.

Python으로 게임과 자동화 스크립트를 만들고, HTML5·CSS3·JavaScript로 설치 없이 브라우저에서 바로 실행되는 결과물을 만듭니다. 작게 만들어 바로 실행해 보고, 빠르게 고쳐 나가는 과정을 좋아합니다.

  1. 기획 원하는 결과를 명확한 문장으로 정리
  2. 구현 AI와 함께 코드를 빠르게 작성
  3. 검증 직접 실행하고 결과를 확인
  4. 개선 피드백을 반영해 반복
